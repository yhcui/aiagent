# 5分钟桌面倒计时器 — 实施计划

## 需求（已确认）

- Windows 桌面应用，每轮 5 分钟倒计时
- 到时提醒（声音 + 视觉闪烁），**提醒后不自动循环**：停在 00:00，点击"再来一轮"手动开始下一轮
- 记录已完成轮数
- 界面按 frontend-design 技能设计

## 技术选型

- **Python 3.12 + tkinter**（本机已确认可用，含 `winsound` 提示音模块），零第三方依赖
- 高分屏 DPI 感知（`SetProcessDpiAwareness`），保证清晰渲染

## 设计方案（frontend-design 两轮流程）

**主题**：5分钟一轮的节奏铃。最有特征的元素 = 瑞士铁路钟 / Braun 厨房计时器的**红色扫针表盘**。

**色彩 tokens**

| 名称 | 值 | 用途 |
|---|---|---|
| FACE | `#FBFBF7` | 表盘纸白 |
| INK | `#191919` | 刻度、数字、正文 |
| RED | `#E20612` | 扫针、已走时弧、提醒闪烁 |
| TRACK | `#DDDDD6` | 未走时轨道 |
| GREY | `#8A877E` | 次级文字 |

**字体**：数字 = Bahnschrift SemiBold（DIN 血统，已确认系统安装）；中文 = Microsoft YaHei UI。无全大写眉标、无等宽数据标签。

**布局**（竖向窗口 380×约540，沿中轴居中）：

```
┌────────────────────────────┐
│  5分钟计时          声音 开 │ ← 标题 + 声音开关
│                            │
│        ╭─── 5 ───╮         │
│      ╱      |     ╲        │
│    4        |      1       │ ← 整圈=5分钟，分钟刻度1–5
│    │    02:41      │       │    红针顺时针扫过，红色已走弧
│    3              2        │    中央 Bahnschrift 读秒
│      ╲           ╱         │
│        ╰───────╯           │
│         已完成 3 轮         │
│                            │
│    [ 开始 ]   [ 重置 ]     │ ← 主按钮墨色填充，次按钮描边
└────────────────────────────┘
```

**行为状态机**

- 状态：`idle`(05:00) → `running` → `paused` → `finished`(00:00)
- 主按钮文案：开始 → 暂停 → 继续 → **再来一轮**（重置并立即开始）
- 重置：回 idle，时间与轮次清零
- 到时：`winsound` 三声 880Hz 提示音 + 表盘红/白闪烁 3 次（约1秒，全应用唯一编排动效），读秒变红，轮次 +1，停在 00:00 等待手动继续
- 计时引擎：`time.monotonic()` + `after(50ms)` 平滑驱动，暂停/继续基于剩余时间

**自查**：无奶油+陶土、无黑底酸性色、无卡片阴影渐变、无 eyebrow/中点/箭头按钮；刻度 1–5 是真实序列；唯一记忆点 = 红针表盘。
