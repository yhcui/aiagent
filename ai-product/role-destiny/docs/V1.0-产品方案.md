# 角色测算小程序 V1.0 产品方案

> **版本**：V1.0 MVP  
> **更新日期**：2026-09-01  
> **定价策略**：统一 ¥0.99  
> **核心目标**：验证商业闭环（测试→付费→查看→分享）

---

## 一、产品概述

### 1.1 产品定位

一款基于微信小程序的趣味角色测算工具，通过简短的心理测试题，匹配用户与特定故事世界中的角色原型，满足用户的**好奇心**和**社交展示需求**。

### 1.2 目标用户

| 维度 | 描述 |
|-----|------|
| **核心人群** | 18-30岁女性 |
| **用户特征** | 喜欢追剧、小说、星座测试、热衷朋友圈分享 |
| **使用场景** | 碎片时间（通勤、午休、睡前） |
| **付费意愿** | 低门槛（¥0.99），冲动型消费 |

### 1.3 V1.0 核心功能范围

```
✅ 必做（P0）
├── 单一测试主题（5-8道题 + 6-8个角色原型）
├── 测试流程（答题 → 结果预览 → 付费解锁）
├── 微信支付（¥0.99 统一定价）
└── 分享海报生成

⚠️ 保留（影响转化率）
├── 免费预览 + 模糊效果
├── 悬念动画效果（"正在计算中..."）
├── 基础数据埋点
└── 微信授权登录（获取昵称/头像）

❌ 砍掉（V1.1/V1.2 再做）
├── 多个测试主题
├── 用户注册/账号系统
├── 积分/会员体系
├── 邀请裂变/拼团
├── 排行榜
├── 评论区/社区
├── 运营后台
└── 复杂数据分析面板
```

### 3.1 V1.0 测试主题示例：「古代宫廷命运测试」

> ⚠️ **版权提示**：使用原创角色原型体系，不直接引用任何具体影视/文学作品中的角色名称。

#### 角色原型设计（6-8个）

| 角色代号 | 角色名称 | 性格关键词 | 命运走向 | 目标用户共鸣点 |
|---------|---------|-----------|---------|--------------|
| A | **深谋远虑的掌权者** | 智慧、冷静、隐忍 | 从幕后走到台前，最终掌控全局 | 有野心但低调的人 |
| B | **纯真无邪的宠儿** | 天真、善良、被宠爱 | 一生顺遂，但缺乏主见 | 渴望简单幸福的人 |
| C | **坚韧不屈的逆袭者** | 倔强、不服输、成长型 | 历经磨难，终成大器 | 正在奋斗的人 |
| D | **温婉贤淑的守护者** | 温柔、包容、牺牲型 | 默默付出，成全他人 | 重视家庭感情的人 |
| E | **锋芒毕露的挑战者** | 直率、敢爱敢恨、冲动 | 大起大落，活得精彩 | 性格鲜明的人 |
| F | **神秘莫测的观察者** | 冷静、洞察力强、旁观者清 | 看透一切，选择独善其身 | 喜欢思考的人 |
| G | **命运多舛的悲剧者** | 敏感、多情、易受伤 | 经历波折，但内心强大 | 感性细腻的人 |
| H | **逍遥自在的隐士** |洒脱、不羁、看淡名利 | 超脱世俗，活出自我 | 向往自由的人 |

#### 题目设计示例（5-8道）

**题目1：如果穿越到古代宫廷，你首先会做什么？**

- A. 先观察环境，了解局势（选A倾向：A/F）
- B. 结识新朋友，建立人脉（选B倾向：B/D）
- C. 努力提升自己的能力（选C倾向：C/E）
- D. 找个安静的地方待着（选D倾向：G/H）

**题目2：面对不公平的待遇，你的第一反应是？**

- A. 忍耐等待时机反击（选A倾向：A/C）
- B. 直接表达不满（选B倾向：E/G）
- C. 寻求他人帮助（选C倾向：B/D）
- D. 无所谓，不在乎（选D倾向：F/H）

**（其余题目类似，每道题4个选项，对应不同角色倾向）**

## 四、付费转化设计

### 4.1 转化漏斗模型

```
首页访问(100%) 
    ↓ 点击"开始测试"(目标:60%+)
    ↓ 
完成答题(目标:80%+) 
    ↓ 
到达结果预览页(100%)
    ↓ 
点击付费按钮(目标:20%+)
    ↓ 
完成支付(目标:15%+)
    ↓ 
查看完整结果(100%)
    ↓ 
生成分享海报(目标:50%+)
    ↓ 
实际分享(目标:30%+)
```

### 4.2 关键转化技巧

| 技巧 | 应用位置 | 具体做法 |
|-----|---------|---------|
| **好奇心缺口** | 结果预览页 | 只显示角色名+一句话，其他全部模糊处理 |
| **锚定效应** | 付费按钮 | 显示原价¥9.99，现价¥0.99（限时特惠） |
| **社会认同** | 首页/测试页 | "已有 12,580 人参与测试"、"3分钟前 xxx 测出了..." |
| **稀缺感** | 付费按钮 | "仅限今日 ¥0.99"、"还剩 23 个优惠名额" |
| **沉没成本** | 测试过程 | 答完题后用户已投入时间精力，更愿意付费看结果 |
| **即时满足** | 支付后 | 立即显示完整结果，无需等待 |
| **损失厌恶** | 分享引导 | "不分享就浪费了这么好的结果" |

### 4.3 定价策略

| 项目 | 说明 |
|-----|------|
| **统一定价** | ¥0.99（不论新老用户） |
| **价格心理学** | 不到1元，降低决策门槛；以9结尾，感觉更便宜 |
| **对比锚点** | UI上可显示"原价 ¥9.99"，增强超值感 |
| **未来涨价空间** | V1.1 可尝试 ¥1.99 或 ¥2.99 |

## 六、数据埋点规划

### 6.1 核心埋点事件

| 事件名称 | 触发时机 | 参数 | 用途 |
|---------|---------|------|------|
| `page_view` | 页面访问 | page_name, from_source | 流量分析 |
| `test_start` | 点击开始测试 | - | 转化漏斗起点 |
| `test_complete` | 完成答题 | total_questions, time_spent | 完题率统计 |
| `result_preview` | 到达结果预览页 | role_id | 展示不同角色的分布 |
| `pay_click` | 点击付费按钮 | role_id, price | 付费意向分析 |
| `pay_success` | 支付成功 | order_id, price, pay_method | 收入统计 |
| `poster_generate` | 生成海报 | role_id | 海报生成率 |
| `poster_share` | 分享海报 | share_type (friend/timeline) | 分享率统计 |
| `share_click` | 通过分享链接进入 | share_user_id | 裂变效果追踪 |

### 6.2 核心KPI指标

| 指标 | 计算公式 | V1.0 目标值 |
|-----|---------|------------|
| **测试完成率** | 完成答题人数 / 开始测试人数 | ≥ 80% |
| **付费转化率** | 付费人数 / 到达结果页人数 | ≥ 15% |
| **ARPU** | 总收入 / 总用户数 | ≥ ¥0.15 |
| **海报生成率** | 生成海报数 / 付费用户数 | ≥ 50% |
| **分享率** | 实际分享数 / 生成海报数 | ≥ 30% |
| **K因子** | 平均每个用户带来新用户数 | ≥ 1.2 |

## 七、UI/UX 设计要点

### 7.1 视觉风格建议

| 元素 | 建议 |
|-----|------|
| **整体色调** | 根据测试主题定（如宫廷风：金色+深红/墨绿） |
| **字体** | 微信默认字体即可，标题可加粗 |
| **按钮样式** | 圆角矩形，主色调醒目，点击有反馈动画 |
| **图标** | 简洁扁平或轻微拟物，符合主题氛围 |
| **动效** | 页面切换流畅，加载有动画，结果揭示有仪式感 |

### 7.2 关键页面线框描述

**首页**
- 顶部：产品Logo + Slogan（如"测测你在古代宫廷的命运角色"）
- 中部：大幅测试主题插画/海报
- 底部：醒目的"开始测试"按钮（主CTA）
- 底部固定栏：滚动提示条（"刚刚 xxx 测出了 【纯真无邪的宠儿】"）

**测试页**
- 顶部：进度条（如"3/8"）+ 返回按钮
- 中部：题目文字（大字号，居中）
- 下部：4个选项按钮（纵向排列，足够间距）
- 底部："下一题"按钮（选中选项后激活）

**结果预览页**
- 背景：模糊处理的完整结果图
- 前景：清晰显示角色名称 + 一句话描述
- 底部：大号付费按钮 + 小号"先看看别人的结果"（跳转到分享墙，可选）

**完整结果页**
- 顶部：角色大图/插画
- 中部：分段展示详细信息（性格/命运/优势/建议）
- 底部：固定"生成海报"按钮

## 八、异常场景处理

| 异常场景 | 处理方式 |
|---------|---------|
| **网络异常** | 本地缓存已答题目，恢复后可继续；提示"网络不稳定，请检查连接" |
| **支付失败** | 提示原因（余额不足/取消支付/系统错误）；提供重试按钮 |
| **支付成功但未回调** | 提供"我已付款"按钮，手动查询订单状态 |
| **中途退出测试** | 下次进入可选择"继续上次测试"或"重新开始" |
| **海报生成失败** | 提示"生成失败，请重试"；降级为文字分享 |
| **重复测试** | 允许免费重新测试（增加粘性）；第二次付费可打折（V1.1功能） |
