### 1.2 技术栈选型（轻量级优化版）

| 层级 | 技术 | 版本 | 选型理由 |
|-----|------|------|---------|
| **前端** | 微信小程序原生 | - | 官方支持最好，性能最优 |
| **后端** | **Python 3.9+ / FastAPI** | 0.95+ | 轻量高性能、异步支持、自动API文档、开发效率高 |
| **数据库** | **SQLite 3** | 3.35+ | 零配置、单文件部署、无需额外服务、适合中小规模应用 |
| **ORM** | **SQLAlchemy 2.0** | 2.0+ | 成熟稳定、支持异步、SQLite完美兼容 |
| **缓存** | **cachetools (LRU)** | 5.x | 纯内存缓存、零依赖、LRU淘汰策略、足够应对单机场景 |
| **验证** | **Pydantic 2.0** | 2.0+ | 数据校验、类型提示、与FastAPI深度集成 |
| **海报生成** | **Pillow + Canvas** | 10.x / 0.3.x | 纯Python图片处理、无需浏览器环境 |
| **部署** | **单进程运行 / systemd** | - | 极简部署、无需Docker（可选） |
| **云服务** | 腾讯云轻量服务器 | 2核4G | 性价比高、微信生态兼容性好 |

### 1.3 为什么选择这个轻量级技术栈？

```
✅ 核心优势：
├── 零运维成本
│   ├── SQLite：无需安装数据库服务，一个文件搞定
│   ├── 内存缓存：无需Redis服务，进程内直接用
│   └── 单机部署：一台服务器跑所有服务
│
├── 快速开发
│   ├── Python生态丰富，库多且成熟
│   ├── FastAPI自动生成API文档（Swagger UI）
│   └── Pydantic自动数据校验，减少样板代码
│
├── 低资源占用
│   ├── 内存占用 < 200MB（vs Node.js+MySQL+Redis > 1GB）
│   ├── 启动速度秒级
│   └── 适合2核4G入门云服务器
│
└── 易于调试
    ├── 单文件数据库可直接查看
    ├── 日志和错误信息清晰
    └── 本地开发和生产环境一致
```

### 1.4 适用场景评估

```
✅ 适合使用此技术栈的场景：
├── 日活用户 < 10,000（MVP阶段完全够用）
├── 单服务器部署（避免分布式复杂度）
├── 快速验证产品想法（时间成本优先）
├── 团队规模小（1-3人全栈）
└── 预算有限（月成本 < ¥200）

⚠️ 未来可能需要升级的场景：
├── 日活 > 50,000 → 升级 PostgreSQL
├── 需要分布式缓存 → 引入 Redis
├── 多服务器负载均衡 → 引入 MySQL/PG + Redis
└── 团队扩张到 10+ 人 → 可考虑微服务
```

### 2.2 SQLite 特性与优势

```
✅ 为什么选择 SQLite：
├── 零配置：无需安装数据库服务，一个 .db 文件即可
├── 单文件部署：备份迁移只需复制文件
├── 跨平台：Windows/Linux/Mac 完全兼容
├── 高性能：读操作极快，适合中小规模应用
├── 可靠性：ACID事务支持，数据安全有保障
├── 低资源：内存占用 < 10MB，适合轻量服务器
└── Python原生支持：sqlite3 标准库，无需额外安装

⚠️ 注意事项：
├── 并发写入限制：同一时间只允许一个写操作（但读可以并发）
├── 适用场景：日活 < 10万，单机部署完全够用
└── 数据库文件位置：建议放在 /data 目录下定期备份
```

### 2.3 表结构详细定义（SQLite语法）

#### 用户表 `users`

```sql
CREATE TABLE IF NOT EXISTS users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  openid TEXT NOT NULL UNIQUE,
  unionid TEXT,
  nickname TEXT,
  avatar TEXT,
  phone TEXT,
  status INTEGER DEFAULT 1 CHECK(status IN (0, 1)),
  created_at TEXT DEFAULT (datetime('now', 'localtime')),
  updated_at TEXT DEFAULT (datetime('now', 'localtime'))
);

-- 创建索引
CREATE INDEX IF NOT EXISTS idx_users_unionid ON users(unionid);
```

#### 测试主题表 `tests`

```sql
CREATE TABLE IF NOT EXISTS tests (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  description TEXT,
  cover_image TEXT,
  share_title TEXT,
  share_desc TEXT,
  price REAL DEFAULT 0.99,
  status INTEGER DEFAULT 1 CHECK(status IN (0, 1)),
  sort_order INTEGER DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now', 'localtime')),
  updated_at TEXT DEFAULT (datetime('now', 'localtime'))
);
```

#### 题目表 `questions`

```sql
CREATE TABLE IF NOT EXISTS questions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  test_id INTEGER NOT NULL,
  content TEXT NOT NULL,
  sort_order INTEGER DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now', 'localtime')),
  FOREIGN KEY (test_id) REFERENCES tests(id)
);

-- 创建索引
CREATE INDEX IF NOT EXISTS idx_questions_test_id ON questions(test_id);
```

#### 选项表 `options`

```sql
CREATE TABLE IF NOT EXISTS options (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  question_id INTEGER NOT NULL,
  content TEXT NOT NULL,
  score_map TEXT,  -- JSON字符串存储，如 '{"A":2,"B":1,"C":0,"D":1}'
  sort_order INTEGER DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now', 'localtime')),
  FOREIGN KEY (question_id) REFERENCES questions(id)
);

-- 创建索引
CREATE INDEX IF NOT EXISTS idx_options_question_id ON options(question_id);
```

#### 角色原型表 `roles`

```sql
CREATE TABLE IF NOT EXISTS roles (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  test_id INTEGER NOT NULL,
  name TEXT NOT NULL,
  code TEXT NOT NULL,
  description TEXT,  -- 一句话描述（免费预览显示）
  image TEXT,
  detail_text TEXT,  -- 详细分析报告（JSON或纯文本）
  personality TEXT,  -- 性格画像
  destiny TEXT,      -- 命运走向
  advantages TEXT,   -- JSON数组
  weaknesses TEXT,   -- JSON数组
  suggestion TEXT,   -- 给用户的建议
  lucky_number TEXT,
  lucky_color TEXT,
  motto TEXT,
  rarity REAL,
  sort_order INTEGER DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now', 'localtime')),
  FOREIGN KEY (test_id) REFERENCES tests(id)
);

-- 创建索引
CREATE INDEX IF NOT EXISTS idx_roles_test_id ON roles(test_id);
```

#### 用户测试记录表 `user_tests`

```sql
CREATE TABLE IF NOT EXISTS user_tests (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL,
  test_id INTEGER NOT NULL,
  answers TEXT NOT NULL,  -- JSON数组
  result_role_id INTEGER,
  match_score REAL,
  is_paid INTEGER DEFAULT 0 CHECK(is_paid IN (0, 1)),
  paid_at TEXT,
  status TEXT DEFAULT 'completed' CHECK(status IN ('completed', 'expired')),
  created_at TEXT DEFAULT (datetime('now', 'localtime')),
  FOREIGN KEY (user_id) REFERENCES users(id),
  FOREIGN KEY (test_id) REFERENCES tests(id),
  FOREIGN KEY (result_role_id) REFERENCES roles(id)
);

-- 创建索引
CREATE INDEX IF NOT EXISTS idx_user_tests_user_id ON user_tests(user_id);
CREATE INDEX IF NOT EXISTS idx_user_tests_test_id ON user_tests(test_id);
```

#### 订单表 `orders`

```sql
CREATE TABLE IF NOT EXISTS orders (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  order_no TEXT NOT NULL UNIQUE,
  user_id INTEGER NOT NULL,
  result_id INTEGER NOT NULL,
  test_id INTEGER NOT NULL,
  amount REAL NOT NULL,
  status TEXT DEFAULT 'pending' CHECK(status IN ('pending', 'paid', 'refunded', 'failed')),
  transaction_id TEXT,
  pay_time TEXT,
  expire_time TEXT,
  created_at TEXT DEFAULT (datetime('now', 'localtime')),
  updated_at TEXT DEFAULT (datetime('now', 'localtime')),
  FOREIGN KEY (user_id) REFERENCES users(id),
  FOREIGN KEY (result_id) REFERENCES user_tests(id),
  FOREIGN KEY (test_id) REFERENCES tests(id)
);

-- 创建索引
CREATE INDEX IF NOT EXISTS idx_orders_user_id ON orders(user_id);
CREATE INDEX IF NOT EXISTS idx_orders_transaction_id ON orders(transaction_id);
```

### 2.4 数据库初始化脚本（Python）

```python
# init_db.py - 初始化SQLite数据库
import sqlite3
import os

DB_PATH = os.path.join(os.path.dirname(__file__), 'data', 'role_destiny.db')

def init_database():
    """初始化数据库和所有表"""
    # 确保data目录存在
    os.makedirs(os.path.dirname(DB_PATH), exist_ok=True)

    conn = sqlite3.connect(DB_PATH)
    cursor = conn.cursor()

    # 执行建表SQL（上面的所有CREATE TABLE语句）
    with open('schema.sql', 'r', encoding='utf-8') as f:
        sql = f.read()
        cursor.executescript(sql)

    conn.commit()
    conn.close()
    print(f"✅ 数据库初始化完成：{DB_PATH}")

if __name__ == '__main__':
    init_database()
```

```python
"""
角色测算小程序 - FastAPI后端主入口
"""
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from contextlib import asynccontextmanager
import uvicorn

from app.config import settings
from app.database import engine, Base
from app.api import auth, quiz, payment, poster, stats
from app.services.cache_service import cache_service


@asynccontextmanager
async def lifespan(app: FastAPI):
    """应用生命周期管理"""
    # 启动时：创建数据库表 + 初始化缓存
    print("🚀 启动中...")
    Base.metadata.create_all(bind=engine)
    cache_service.warmup()  # 预热缓存
    print("✅ 启动完成！")
    yield
    # 关闭时：清理资源
    print("👋 关闭中...")


app = FastAPI(
    title="角色测算小程序API",
    description="微信小程序后端服务",
    version="1.0.0",
    lifespan=lifespan
)

# CORS中间件配置
app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.ALLOW_ORIGINS,
    allow_credentials=True,
    allow_methods=["*"],

# 注册路由
app.include_router(auth.router, prefix="/api/auth", tags=["认证"])

app.include_router(payment.router, prefix="/api/payment", tags=["支付"])

if __name__ == "__main__":
```

#### 数据库连接 `database.py`

```python
"""
SQLAlchemy数据库配置 - SQLite版本
"""
from sqlalchemy import create_engine
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker
from app.config import settings

# 创建SQLite引擎
engine = create_engine(
    settings.DATABASE_URL,
    connect_args={"check_same_thread": False},  # SQLite特有配置
    echo=settings.DEBUG  # 打印SQL语句（开发环境）
)

# 创建会话工厂
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)

# 声明基类
Base = declarative_base()


def get_db():
    """获取数据库会话（依赖注入用）"""
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

```python
适用于单机部署场景，替代Redis
"""
from cachetools import TTLCache
from typing import Optional, Any
import time
import json
import logging

logger = logging.getLogger(__name__)


class CacheService:
    """基于LRU的内存缓存服务"""

    def __init__(self, maxsize: int = 1000, ttl: int = 300):
        """
        初始化缓存

        Args:
            maxsize: 最大缓存条目数
            ttl: 过期时间（秒）
        """
        self.cache = TTLCache(maxsize=maxsize, ttl=ttl)
        self._stats = {
            'hits': 0,
            'misses': 0
        }

    def get(self, key: str) -> Optional[Any]:
        """获取缓存值"""
        value = self.cache.get(key)
        if value is not None:
            self._stats['hits'] += 1
            logger.debug(f"缓存命中: {key}")
            return value
        else:
            self._stats['misses'] += 1
            logger.debug(f"缓存未命中: {key}")
            return None

    def set(self, key: str, value: Any, ttl: Optional[int] = None) -> None:
        """设置缓存值"""
        try:
            self.cache[key] = value
            logger.debug(f"设置缓存: {key}")
        except Exception as e:
            logger.error(f"设置缓存失败: {key}, 错误: {e}")

    def delete(self, key: str) -> None:
        """删除缓存"""
        if key in self.cache:
            del self.cache[key]
            logger.debug(f"删除缓存: {key}")

    def clear(self) -> None:
        """清空所有缓存"""
        self.cache.clear()
        logger.info("缓存已清空")

    def warmup(self) -> None:
        """预热缓存（加载热点数据）"""
        # 示例：预加载测试题目到缓存
        logger.info("缓存预热完成")

    def get_stats(self) -> dict:
        """获取缓存统计信息"""
        total = self._stats['hits'] + self._stats['misses']
        hit_rate = (self._stats['hits'] / total * 100) if total > 0 else 0

            'hit_rate': f"{hit_rate:.2f}%",
```

### 4.1 角色匹配算法

```python
"""
角色匹配算法 - Python版本
根据用户答案计算匹配的角色
"""
from typing import List, Dict, Any
import random
import json


def calculate_role_match(
    answers: List[Dict[str, int]],
    questions: List[Dict[str, Any]],
    roles: List[Dict[str, Any]]
) -> Dict[str, Any]:
    """
    计算角色匹配结果

    Args:
        answers: 用户答案列表 [{question_id: 1, option_id: 2}, ...]
        questions: 题目列表（含选项的score_map）
        roles: 角色列表

    Returns:
        匹配结果字典 {role_id, role_name, match_score, scores}
    """
    # 初始化各角色的得分
    scores = {role['code']: 0 for role in roles}

    # 累加每个答案的得分
    for answer in answers:
        question = next(
            (q for q in questions if q['id'] == answer['question_id']),
            None
        )
        if not question:
            continue

        option = next(
            (o for o in question.get('options', [])
             if o['id'] == answer['option_id']),
            None
        )

        if not option or not option.get('score_map'):
            continue

        # score_map格式: {"A": 2, "B": 1, "C": 0, "D": 1}
        score_map = option['score_map']
        if isinstance(score_map, str):
            score_map = json.loads(score_map)

        for role_code, score in score_map.items():
            if role_code in scores:
                scores[role_code] += int(score)

    # 找出得分最高的角色
    if not scores or all(s == 0 for s in scores.values()):
        # 如果没有有效分数，随机分配一个角色
        matched_role = random.choice(roles) if roles else None
        match_score = round(random.uniform(85, 98), 1)
    else:
        max_code = max(scores.keys(), key=lambda k: scores[k])
        matched_role = next((r for r in roles if r['code'] == max_code), None)

        # 计算匹配度百分比
        total_possible = len(questions) * 2  # 假设每题最高2分
        max_score = scores[max_code]
        match_score = round(min((max_score / total_possible) * 100, 99), 1)

    return {
        'role_id': matched_role['id'] if matched_role else None,
        'role_name': matched_role['name'] if matched_role else None,
        'match_score': match_score,
        'scores': scores
    }
```

```python
"""
微信支付服务 - Python实现
"""
import hashlib
import time
import random
import string
import xml.etree.ElementTree as ET
from typing import Optional
from loguru import logger
import httpx


class WeChatPayService:
    """微信支付V2版本封装"""

    def __init__(self, app_id: str, mch_id: str, api_key: str, notify_url: str):
        self.app_id = app_id
        self.mch_id = mch_id
        self.api_key = api_key
        self.notify_url = notify_url
        self.unified_order_url = "https://api.mch.weixin.qq.com/pay/unifiedorder"

    def _generate_sign(self, params: dict) -> str:
        """生成签名"""
        sorted_params = sorted(params.items())
        string_a = "&".join([f"{k}={v}" for k, v in sorted_params if v])
        string_sign_temp = f"{string_a}&key={self.api_key}"
        sign = hashlib.md5(string_sign_temp.encode('utf-8')).hexdigest().upper()
        return sign

    def _generate_nonce_str(self) -> str:
        """生成随机字符串"""
        return ''.join(random.choices(string.ascii_letters + string.digits, k=32))

    async def create_order(
        self,
        order_no: str,
        total_fee: int,  # 单位：分
        body: str,
        openid: str
    ) -> dict:
        """创建支付订单"""
        params = {
            'appid': self.app_id,
            'mch_id': self.mch_id,
            'nonce_str': self._generate_nonce_str(),
            'body': body,
            'out_trade_no': order_no,
            'total_fee': total_fee,
            'spbill_create_ip': '127.0.0.1',
            'notify_url': self.notify_url,
            'trade_type': 'JSAPI',
            'openid': openid
        }

        params['sign'] = self._generate_sign(params)
        xml_data = self._dict_to_xml(params)

        async with httpx.AsyncClient(timeout=10.0) as client:
            response = await client.post(
                self.unified_order_url,
                content=xml_data,
                headers={'Content-Type': 'application/xml'}
            )

        result = self._xml_to_dict(response.text)

        if result.get('return_code') == 'SUCCESS' and result.get('result_code') == 'SUCCESS':
            pay_params = self._generate_pay_params(result['prepay_id'])
            return {
                'success': True,
                'prepay_id': result['prepay_id'],
                'pay_params': pay_params
            }
        else:
            error_msg = result.get('return_msg') or result.get('err_code_des')
            raise Exception(f"创建订单失败: {error_msg}")

    def _generate_pay_params(self, prepay_id: str) -> dict:
        """生成小程序调起支付所需参数"""
        timestamp = str(int(time.time()))
        nonce_str = self._generate_nonce_str()
        package = f"prepay_id={prepay_id}"

        params = {
            'appId': self.app_id,
            'timeStamp': timestamp,
            'nonceStr': nonce_str,
            'package': package,
            'signType': 'MD5'
        }

        params['paySign'] = self._generate_sign(params)
        return params

    def verify_callback(self, xml_data: str) -> Optional[dict]:
        """验证支付回调通知"""
        try:
            data = self._xml_to_dict(xml_data)
            sign = data.pop('sign', '')
            calculated_sign = self._generate_sign(data)

            if sign != calculated_sign:
                logger.warning("支付回调签名验证失败")
                return None

            return data
        except Exception as e:
            logger.error(f"解析支付回调失败: {e}")
            return None

    @staticmethod
    def _dict_to_xml(data: dict) -> str:
        """字典转XML"""
        xml = '<xml>'
        for key, value in data.items():
            xml += f'<{key}><![CDATA[{value}]]></{key}>'
        xml += '</xml>'
        return xml

    @staticmethod
    def _xml_to_dict(xml_data: str) -> dict:
        """XML转字典"""
        root = ET.fromstring(xml_data)
        return {child.tag: child.text for child in root}
```

### 4.3 海报生成逻辑 - Python Pillow实现

```python
"""
海报生成服务 - 使用Pillow绘制Canvas
无需浏览器环境，轻量高效
"""
from PIL import Image, ImageDraw, ImageFont
from io import BytesIO
import base64
import os


class PosterGenerator:
    """
    分享海报生成器

    特点：
    - 纯Python实现，无需Puppeteer/浏览器
    - 内存占用低（<50MB vs Puppeteer >200MB）
    - 生成速度快（<1秒 vs Puppeteer >3秒）
    """

    WIDTH = 750
    HEIGHT = 1334

    COLORS = {
        'gradient_start': (255, 107, 157),
        'gradient_mid': (177, 156, 217),
        'gradient_end': (135, 206, 235),
        'white': (255, 255, 255),
        'text_dark': (51, 51, 51),
    }

    def __init__(self, static_dir: str = "./static"):
        self.static_dir = static_dir
        self.font_dir = os.path.join(static_dir, "fonts")
        os.makedirs(self.font_dir, exist_ok=True)

    def generate(self, data: dict) -> str:
        """生成分享海报，返回base64编码的图片"""
        img = Image.new('RGB', (self.WIDTH, self.HEIGHT))
        draw = ImageDraw.Draw(img)

        # 绘制渐变背景
        self._draw_gradient(draw)

        # 绘制角色图片
        if data.get('image'):
            self._draw_image(img, data['image'], center_y=280, size=200)

        # 绘制文字信息
        self._draw_text(draw, f"✨ {data.get('role_name', '')} ✨", y=500, size=40, bold=True)
        self._draw_text(draw, data.get('description', ''), y=580, size=28)

        # 绘制匹配度圆环
        self._draw_ring(draw, data.get('match_score', 92), cx=self.WIDTH//2, cy=680)

        # 绘制分割线和文案
        self._draw_line(draw, y=760)
        self._draw_text(draw, f'"${data.get("quote", "")}"', y=830, size=26)

        # 绘制二维码
        if data.get('qrcode'):
            self._draw_qrcode(img, draw, data['qrcode'], y=1050)

        # 导出为base64
        buffer = BytesIO()
        img.save(buffer, format='PNG')
        return f"data:image/png;base64,{base64.b64encode(buffer.getvalue()).decode()}"

    def _draw_gradient(self, draw: ImageDraw.Draw):
        """绘制渐变背景"""
        for y in range(self.HEIGHT):
            ratio = y / self.HEIGHT
            if ratio < 0.5:
                r = ratio * 2
                color = tuple(int(self.COLORS['gradient_start'][i] * (1-r) +
                                self.COLORS['gradient_mid'][i] * r) for i in range(3))
            else:
                r = (ratio - 0.5) * 2
                color = tuple(int(self.COLORS['gradient_mid'][i] * (1-r) +
                                self.COLORS['gradient_end'][i] * r) for i in range(3))
            draw.line([(0, y), (self.WIDTH, y)], fill=color)

    def _draw_text(self, draw: ImageDraw.Draw, text: str, y: int, size: int = 28, bold: bool = False, color=None):
        """居中绘制文字"""
        if color is None:
            color = self.COLORS['white']
        try:
            font = ImageFont.truetype(os.path.join(self.font_dir, "PingFangSC-Medium.ttf"), size)
        except:
            font = ImageFont.load_default()

        bbox = draw.textbbox((0, 0), text, font=font)
        x = (self.WIDTH - (bbox[2] - bbox[0])) // 2
        draw.text((x, y), text, font=font, fill=color)

    def _draw_ring(self, draw: ImageDraw.Draw, pct: float, cx: int, cy: int):
        """绘制匹配度圆环"""
        r = 60
        draw.ellipse([cx-r, cy-r, cx+r, cy+r], outline=(255,255,255,128), width=8)
        draw.arc([cx-r, cy-r, cx+r, cy+r], start=-90, end=-90+(pct/100)*360, fill=(255,255,255), width=8)
        self._draw_text(draw, f"{int(pct)}%", y=cy-18, size=32, bold=True)

    def _draw_line(self, draw: ImageDraw.Draw, y: int):
        """绘制分割线"""
        w = 400
        x = (self.WIDTH - w) // 2
        draw.line([(x, y), (x+w, y)], fill=(255,255,255,128), width=2)

    def _draw_qrcode(self, img: Image.Image, draw: ImageDraw.Draw, path: str, y: int):
        """绘制二维码"""
        try:
            qr = Image.open(path).resize((120, 120))
            px = (self.WIDTH - 140) // 2
            draw.rectangle([px-10, y-10, px+150, y+150], fill=(255,255,255))
```

## 附录

### A. 常见问题 FAQ

**Q1: SQLite能支撑多少并发？**
A: SQLite读操作可以完全并发，写操作需要串行。对于日活 < 10万的应用完全够用。如果未来遇到瓶颈，可以升级到PostgreSQL。

**Q2: 内存缓存会不会丢失？**
A: 会。但我们的缓存数据都是可重建的（如测试题目），丢失后会自动从数据库重新加载。不影响业务逻辑。

**Q3: 如何备份数据？**
A: SQLite是单文件数据库，直接复制 .db 文件即可。建议每日定时备份。

**Q4: 为什么不用Docker？**
A: MVP阶段为了简化部署，可以直接运行Python脚本。如果需要容器化部署，文档中也提供了Dockerfile。

**Q5: FastAPI相比Flask/Django有什么优势？**
A: 
- 自动生成API文档（Swagger UI）
- 原生支持异步
- 类型提示和Pydantic深度集成
- 性能接近Go（基于Starlette）
