## 1. 设计概述

### 1.1 产品定位

角色测算小程序是一款**趣味性心理测试工具**，通过5-8道选择题为用户匹配古代宫廷命运角色，满足年轻用户的娱乐和社交分享需求。

### 1.2 设计理念

```
✨ 核心设计原则：
├── 色彩明快 - 高饱和度糖果色系，营造轻松愉悦氛围
├── 圆润友好 - 大圆角设计，柔和视觉感受，降低距离感
├── emoji点缀 - 适度使用emoji增强趣味性和情感表达
├── 插画为主 - 卡通风格插画作为视觉核心，提升辨识度
└── 清晰层级 - 通过大小、颜色、间距建立清晰信息层级
```

### 1.3 目标用户特征

| 维度 | 特征 |
|-----|------|
| **年龄** | 18-30岁女性 |
| **兴趣** | 追剧、小说、星座测试、朋友圈分享 |
| **使用场景** | 碎片时间（通勤、午休、睡前） |
| **审美偏好** | 活泼可爱、明亮色彩、卡通元素 |

### 1.4 页面架构

```
首页 (Home) 
    ↓ 点击"开始测试"
测试页 (Quiz) × 5-8题
    ↓ 完成最后一题
结果预览页 (Preview) 
    ↓ 点击付费按钮（¥0.99）
完整结果页 (Result)
    ↓ 点击"生成海报"
分享海报页 (Poster)
```

### 6.1 屏幕尺寸适配

微信小程序主要适配以下屏幕：

| 设备类型 | 屏幕宽度 | 设计基准 | 适配策略 |
|---------|---------|---------|---------|
| **iPhone SE** | 375pt | 750rpx | 最小宽度适配 |
| **iPhone 12/13** | 390pt | 750rpx | 标准适配 |
| **iPhone 14 Pro Max** | 430pt | 750rpx | 最大宽度适配 |
| **Android 各种** | 360-410pt | 750rpx | 弹性布局 |

### 6.2 适配方案

#### 使用 rpx 单位

```css
/* 推荐：使用 rpx 相对单位 */
.container {
  width: 750rpx;  /* 在任何屏幕上都占满宽度 */
  padding: 32rpx; /* 自动按比例缩放 */
}

/* 避免：使用固定 px 值 */
.fixed-width {
  width: 375px;  /* ❌ 在大屏上会显得过小 */
}
```

#### 弹性布局

```css
/* 使用 Flexbox 实现自适应 */
.flex-container {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
}

/* 百分比宽度 */
.flex-item {
  flex: 1;  /* 平均分配空间 */
  min-width: 0;  /* 防止溢出 */
}
```

#### 安全区域

```css
/* 底部安全区域（iPhone X 系列） */
.safe-area-bottom {
  padding-bottom: constant(safe-area-inset-bottom);  /* iOS < 11.2 */
  padding-bottom: env(safe-area-inset-bottom);        /* iOS >= 11.2 */
}

/* 顶部状态栏 */

  height: var(--status-bar-height);  /* 微信提供 */
}
```
