# 🍅 番茄时钟 · Windows 桌面版

一个小巧的番茄工作法计时器：**无需安装、无需登录、不联网**。
双击 `Pomodoro.exe` 即可运行（基于 Windows 自带的 .NET Framework 4，系统原生支持，不用装任何运行时）。

## 功能

- **专注 / 短休息 / 长休息** 自动轮换，每完成 N 个番茄进入一次长休息（N 可配置）
- 圆环倒计时进度，主题色随阶段切换（专注=红、短休息=青、长休息=蓝）
- 阶段结束时的**气泡通知 + 提示音**（提示音由代码合成，不依赖任何音频文件）
- **今日番茄数统计**，按日期本地保存，隔天自动清零
- **系统托盘常驻**：关闭窗口即最小化到托盘，托盘菜单可开始/暂停/重置/跳过/退出，悬停可看到剩余时间
- **开机自启动**：设置页一键开关（写入当前用户注册表 Run 键，不需要管理员权限）
- 可选：窗口始终置顶、启动时最小化到托盘、休息自动开始、休息结束自动开始专注
- 快捷键：`空格` 开始/暂停　`R` 重置　`S` 跳过

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `Pomodoro.exe` | 主程序，可复制到任意位置运行 |
| `Pomodoro.cs` | 全部源码（单文件） |
| `build.bat` | 一键重新编译（使用系统自带 csc.exe） |

## 修改源码后重新编译

直接双击 `build.bat`，或在命令行运行：

```
build.bat
```

## 数据与隐私

- 设置：`%APPDATA%\PomodoroTimer\settings.ini`
- 统计：`%APPDATA%\PomodoroTimer\stats.ini`
- 开机自启：注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `PomodoroTimer` 项

程序不联网、不上传任何数据。**彻底卸载**：删除 `Pomodoro.exe`、`%APPDATA%\PomodoroTimer` 文件夹，并在设置中关闭"开机自动启动"（或直接删除上述注册表项）即可。

## 使用建议

1. 双击 `Pomodoro.exe` 启动；
2. 点右上角 ⚙ 打开设置，按需勾选 **开机自动启动**；
3. 按 `空格` 或点击"开始"进入第一个番茄；
4. 想放到桌面：右键 `Pomodoro.exe` → 发送到 → 桌面快捷方式。
